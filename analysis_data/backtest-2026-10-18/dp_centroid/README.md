## 结果（rules_out.txt）
- 31 条里没有一条按上面的判定"有优势"：28 条没优势，2 条反向（吸筹确认、只看逐级上移：该跑赢的反而略跑输；每段只算第一次时 td 只有 −0.1 / +0.4，很弱），1 条原文就说没方向。5 天跑输比例（基准 55%）：
  - 派发确认 51%；加"涨一段之后" 47%；只看逐级下移 53%
  - 吸筹确认、只看逐级上移：之后跑赢 41–42%（基准 45%），说吸筹的反而略弱
  - Trap warning 60%，但每段只算第一天 55%
  - Confirmed trap 56%（n 166）：分季度 47 / 47 / 61 / 71%。10/27 在 7/22–10/26 测到的 68% / 62% 只在下半年成立；同一段用这份代码重算是 70% / 66%（check_vs_earlier.txt）
  - 价格裁决：3 天内失败 57%（季度 43 / 50 / 65 / 67%）；4–10 天才失败 46%；健康 acceptance 跑赢 49%；回踩 2D 守住跑赢 42%
  - 收盘跌破 2D 53%；第一天 54%、连续 52%、浅 54%、深 52%
  - 站回 2D、收复 1W：之后跑赢 45%，就是基准
  - RULEBOOK 那几条 43–54%；单日冒尖 55%（原文说没方向，确实没方向）
  - 11/12 加的：放量 + 冲高 + 重心没跟上 55%；Olivia 核心做空 47%；ZZ 那条 45%
- 唯一每个季度都高于基准的：Step 4 价格跑在库存前面（step4_grid.txt）
  - 收盘高出 1W 重心 ≥8%：5 天跑输 64%、跌 55%（基准 47%），季度 56 / 65 / 65 / 72%，每段第一次 67% / 61%；但平均超额 +0.7 个点（12–2 月有几只继续暴涨，那季平均 +12.5）
  - 收盘高出 1M 重心 ≥20%：5 天跑输 67%、跌 55%，10 天跌 60%，季度 61 / 65 / 77 / 57%，平均超额 −1.4（β 调整 −2.3）
  - 5 天内跌 ≥5% 的占 40–41%，平时 23%：是回落预警，不是持续下跌
- 但这主要是价格涨过头本身（step4_vs_price.txt）：换成普通均价（收盘高出 21 日均价 ≥20%）是 68% / 59%，一样好
  - 暗池多给的一点：涨过头的票里，1M 重心比 21 日均价低 ≥3%（库存没跟上）的 77% 跑输、跌 63%，每段第一次 84%（n 75 / 31 次）；重心不低的 63–64%。事后拆出来的、样本小，先当观察
